# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for AFK implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation or interaction |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill refers to a canonical triage role, apply the corresponding GitHub label.
